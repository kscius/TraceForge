# Security Policy

## Reporting

Please report vulnerabilities privately by opening a GitHub security advisory on the repository (or email maintainers when available). Do not file public issues for exploitable vulnerabilities.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Scope

Authentication, authorization, webhooks, file uploads, SSRF in URL fetchers, and MCP/API tokens are in scope for security reviews.
